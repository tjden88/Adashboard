# Расширение браузера: добавление карточек

Manifest V3 расширение для Chrome, Edge и Firefox: добавляет текущую вкладку в Adashboard через API — страница, категория и карточка одним действием.

## Сборка

```bash
npm install
npm run build
```

Результат — `dist/` с `manifest.json`, `popup.html`, `options.html`, ассетами и иконками.

Нужен актуальный браузер: код использует `AbortSignal.timeout` и `AbortSignal.any` (Chrome/Edge 124+, Firefox 129+).

## Загрузка

- Chrome и Edge: `chrome://extensions` → «Режим разработчика» → «Load unpacked» → выбрать `dist`.
- Firefox: `about:debugging#/runtime/this-firefox` → «Load Temporary Add-on» → выбрать `dist/manifest.json`.

## Настройка

1. Открыть страницу настроек расширения (кнопка «Настройки» в попапе) и указать адрес сервера, например `http://localhost:8080` — только `http` или `https`, без завершающего `/`.
2. Указать ключ доступа: значение `ExtensionApiKey` из настроек Adashboard (если ключ расширения не задан, подходит основной `ApiKey`). Значения хранятся только в `storage.local` этого браузера, ключ в репозиторий не попадает.
3. «Проверить подключение» выполняет `GET /api/health/access` с заголовком `X-Api-Key` и показывает результат: «Неверный ключ доступа.» при 401, «Не удалось подключиться к серверу.» при сетевой ошибке.

Дальше достаточно открыть http(s)-страницу, нажать иконку расширения, при необходимости поправить заголовок и сохранить карточку. Категорию «Закладки» расширение создаёт только при сохранении, если на странице нет ни одной категории; последняя страница и категория запоминаются.
