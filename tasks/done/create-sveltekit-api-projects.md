# Заготовки проектов для перехода на SvelteKit + ASP.NET Web API

## Цель
Заложить основу для полного рефакторинга: вместо Blazor приложение будет состоять из отдельного фронтенда на SvelteKit и бэкенда на ASP.NET Web API. В рамках этой задачи нужно создать в репозитории пустые заготовки обоих проектов и подключить их к решению, чтобы дальнейшую миграцию функциональности выполнять уже в новой структуре.

## Требования
- Создать в корне репозитория backend-проект `Adashboard.Api` (папка `Adashboard.Api/`, файл `Adashboard.Api.csproj`) на `net10.0`:
  - пустой шаблон ASP.NET Web API (контроллеры или minimal API);
  - подключённый OpenAPI/Swagger;
  - один контроллер/эндпоинт-заглушка (например, `GET /api/health` или `GET /api/hello`);
  - без EF Core, `DbContext`, моделей домена и миграций.
- Создать в корне репозитория frontend-проект `Adashboard.Web` (папка `Adashboard.Web/`) — заготовка SvelteKit:
  - TypeScript;
  - `adapter-node`;
  - пакетный менеджер `npm`;
  - стандартная стартовая страница SvelteKit;
  - минимальная стилизация (базовый CSS), без Tailwind и других CSS-фреймворков;
  - без dev-прокси и без настройки CORS (связь фронтенда и API настраивается позже).
- Добавить `Adashboard.Api` в решение `Adashboard.slnx`. Проект SvelteKit не является .NET-проектом, поэтому в `.slnx` он не добавляется — `Adashboard.Web` размещается как соседняя папка в корне.
- Не изменять и не удалять существующий Blazor-проект `Adashboard`: он временно остаётся в решении и должен продолжать собираться.
- Не трогать `Dockerfile`, `compose.yml` и другую инфраструктуру — это отдельная задача.
- Не добавлять документацию и примеры конфигурации сверх необходимого минимума.

## Критерии приёмки
- [x] В корне появились папки `Adashboard.Api/` и `Adashboard.Web/` с корректной структурой проектов.
- [x] `Adashboard.Api` добавлен в `Adashboard.slnx`, существующий проект `Adashboard` сохранён.
- [x] `dotnet build Adashboard.slnx` успешно собирает решение.

- [x] `npm install` и `npm run dev` в `Adashboard.Web` запускают dev-сервер, стартовая страница открывается.
- [x] Blazor-проект `Adashboard` не изменён и продолжает собираться.
