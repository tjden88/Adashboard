# Новый режим бокового меню: «свёрнуто»

## Цель
Добавить четвёртый режим бокового меню страниц — постоянно свёрнутый. Внешне он совпадает с автосворачиванием в свёрнутом состоянии (узкая полоса с иконками), но не разворачивается ни по наведению, ни по фокусу с клавиатуры. Названия страниц доступны как всплывающая подсказка браузера. Заодно в диалоге настроек сайта режимы меню выбираются выпадающим списком вместо радиокнопок.

## Требования
- `Adashboard.Domain/Enums/SideMenuMode.cs`: добавить значение `Collapsed = 3` (дописывать в конец, существующие числа не менять — они хранятся в БД как `int`, миграция не нужна). XML-комментарий enum обновить, оставив только `<summary>`.
- `SideMenu.razor`: в `NavClass` добавить ветку `SideMenuMode.Collapsed => " side-menu--collapsed"`; комментарий компонента дополнить описанием нового режима.
- `SideMenu.razor.css`: внутри существующего блока `@media (min-width: 901px)` описать `.side-menu--collapsed` так же, как `.side-menu--auto` в свёрнутом виде: `position: fixed`, ширина `var(--side-menu-collapsed-width, 64px)`, рамка справа, `overflow-y: auto`, иконки по центру. Отдельно:
  - не добавлять `:hover`/`:has(:focus-visible)`-разворачивание и `transition` ширины;
  - подписи (`.side-menu-label`) скрыть тем же способом, что в автосворачивании (`visibility: hidden`, `flex: 0 0 0`, `width: 0`), `gap` у ссылок и кнопки редактирования обнулить;
  - в `@media (prefers-reduced-motion: reduce)` ничего дополнительно не требуется, так как анимации у режима нет.
- Всплывающая подсказка — штатный `title`: у ссылок он уже задан (`title="@label"`), у кнопки редактирования — свой `title`. Для доступности добавить ссылкам `aria-label="@label"`, так как скрытые через `visibility: hidden` подписи не читаются скринридером.
- Мобильная версия: режим не применяется. На ширине до 900px меню работает как обычный drawer с полными подписями; стили режима не должны попадать за пределы десктопного медиазапроса. Кнопка меню в шапке (`Header.razor`) должна показываться для нового режима так же, как для автосворачивания и развёрнутого.
- `MainLayout.razor`: в `ShellMenuClass` добавить `SideMenuMode.Collapsed => "shell--menu-collapsed"`; `MainLayout.razor.css` — отступ контента на ширину свёрнутой полосы, такой же, как у `shell--menu-auto` (только десктопный медиазапрос).
- `AppSettingsDialog.razor`: в блоке «Меню страниц» заменить `InputRadioGroup` с радиокнопками на `InputSelect` (`class="form-select"`, как в `CategoryDialog`) со всеми четырьмя вариантами: «Скрыто», «Свёрнуто», «Автосворачивание», «Всегда развёрнуто». Подсказку под списком обновить: описать все четыре режима, включая то, что «Свёрнуто» никогда не разворачивается, а название страницы показывается во всплывающей подсказке, и что на мобильных режим не действует.
- Выбор темы оформления оставить радиокнопками, как есть.
- API, контракты настроек, сущность `AppSettingsEntity` и маппинг Mapster не меняются: значение сохраняется существующим механизмом настроек. Миграцию БД не создавать.

## Критерии приёмки
- [ ] Решение собирается: `dotnet build` проходит без ошибок и новых предупреждений.
- [ ] В диалоге настроек «Меню страниц» — выпадающий список с четырьмя вариантами; тема оформления по-прежнему радиокнопки.
- [ ] Выбранный режим «Свёрнуто» сохраняется и применяется сразу после сохранения настроек, без перезагрузки страницы.
- [ ] На десктопе свёрнутое меню — узкая полоса с иконками; при наведении и при фокусе с клавиатуры ширина не меняется, подписи не появляются.
- [ ] При наведении на пункт меню браузер показывает название страницы как всплывающую подсказку; активная страница подсвечена, переходам по пунктам и кнопке редактирования ничего не мешает.
- [ ] Контент страницы сдвинут ровно на ширину свёрнутой полосы, без пустого места под развёрнутое меню.
- [ ] На мобильной ширине (< 900px) меню открывается кнопкой в шапке как обычный drawer с полными названиями; свёрнутый режим на него не влияет.
- [ ] Режимы «Скрыто», «Автосворачивание» и «Всегда развёрнуто» работают как раньше; ранее сохранённое значение в БД остаётся корректным.
- [ ] Миграция БД не создавалась.
