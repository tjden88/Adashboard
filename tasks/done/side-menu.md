# Боковое меню страниц dashboard

## Цель
Добавить левое боковое меню для переключения между страницами dashboard: пункты меню — иконки и названия страниц, главная страница визуально отделена. Видимость меню настраивается (скрыто, автосворачивание, всегда развёрнуто), на мобильной ширине меню открывается кнопкой.

Задача выполняется **после** `tasks/page-icon.md`: меню использует `DashboardPage.Icon`.

## Требования

### Настройка видимости
- В `Adashboard.Domain.Enums` добавить enum `SideMenuMode` со значениями `Hidden`, `AutoCollapse`, `Expanded`.
- В контракт `AppSettings` и сущность `AppSettingsEntity` добавить свойство `SideMenuMode` со значением по умолчанию `AutoCollapse` (для существующих настроек — тоже автосворачивание); создать и применить миграцию EF Core.
- В `AppSettingsDialog` добавить выбор режима меню (радиогруппа из трёх вариантов с понятными подписями и подсказками), сохранение — через существующий механизм `AppStateService.SaveSettingsAsync`.
- Маппинг «сущность ↔ контракт» оставить на Mapster.

### Компонент меню
- Новый компонент `SideMenu` в `Adashboard.Client/Components/Layout` (отдельный `.razor.css`), регион `nav` с `aria-label`. Пункты строятся из `DashboardPageModel.Pages` в порядке списка страниц; главная страница (пустой `Path`) всегда отделена от остальных визуальным отступом/разделителем.
- Пункт меню: иконка страницы (`Page.Icon`, при пустом значении — `fa-solid fa-file`) и название (`Page.Title`, при пустом — название приложения). Текущая страница выделена и помечена `aria-current="page"`.
- Переход по пункту — через маршрутизацию Blazor без перезагрузки приложения.
- Меню показывается только на найденной загруженной странице (не в состоянии загрузки, ошибки, «не найдено», «сервер не настроен»).
- Меню обновляется без перезагрузки после создания, переименования, изменения иконки и удаления страницы.
- При `Hidden` меню не рисуется и кнопка раскрытия не показывается ни на десктопе, ни на мобильном.

### Режимы отображения
- `Expanded` (десктоп): меню всегда развёрнуто, видны иконки и названия, контент страницы расположен справа.
- `AutoCollapse` (десктоп): свёрнутая узкая полоса только с иконками; при наведении мышью и при попадании фокуса клавиатуры меню раскрывается поверх контента (без сдвига контента), названия показываются; в свёрнутом виде у иконок есть подсказки (`title`/`aria-label`).
- Мобильная ширина (до 900px): меню всегда работает как выдвижная панель (drawer) слева поверх контента с затемнением фона; открывается кнопкой в шапке, закрывается по выбору пункта, по клику вне меню и по `Esc`; фокус возвращается на кнопку открытия, фон под меню не прокручивается.
- Кнопка раскрытия меню в шапке видна только на мобильной ширине и только когда меню доступно; у кнопки `aria-expanded` и понятная подпись.
- Состояние открытости мобильного меню хранится в `AppStateService` (как режим редактирования) и управляется методами открытия/закрытия/переключения; блокировка прокрутки — минимальным JS interop или CSS, без сторонних библиотек.

### Вёрстка и оформление
- Меню вписано в существующий каркас (`MainLayout`/`Home`): на десктопе шапка и содержимое страницы остаются справа от меню, на мобильной ширине занимают всю ширину.
- Стили — через существующие CSS-переменные темы, корректно в светлой и тёмной теме; переходы плавные, с учётом `prefers-reduced-motion`.
- Длинные названия страниц обрезаются многоточием, вёрстка не ломается.
- Клавиатурная навигация и заметный focus сохраняются, подписи элементов понятны скринридеру.
- Комментарии в коде — по правилам проекта (только `summary`, на русском).

## Критерии приёмки
- [ ] В настройках приложения есть выбор «Скрыто / Автосворачивание / Всегда развёрнуто», выбор сохраняется на сервере и применяется сразу после сохранения, миграция создана и применена.
- [ ] На десктопе меню показывает страницы с иконками и названиями, главная страница отделена отступом, текущая страница подсвечена.
- [ ] В режиме автосворачивания меню показывает только иконки и раскрывается при наведении и фокусе поверх контента, не сдвигая страницу.
- [ ] В режиме «Скрыто» меню и кнопка не отображаются на любой ширине.
- [ ] На мобильной ширине кнопка в шапке открывает меню поверх контента с затемнением; меню закрывается по пункту, клику вне и `Esc`.
- [ ] Создание, переименование, смена иконки и удаление страницы сразу отражаются в меню без перезагрузки.
- [ ] На 404, ошибке загрузки и во время загрузки страницы меню не отображается.
- [ ] Проект собирается без ошибок; после изменения API выполнены две сборки (обновление OpenAPI и пересборка клиента).
