# Свойство карточки: способ открытия ссылки

## Цель
Дать каждой карточке настраиваемый способ открытия ссылки: в новой вкладке (текущее поведение) или в текущей вкладке. Сейчас все карточки жёстко открываются в новой вкладке (`target="_blank"` в `Card.razor`), и выбор должен переехать в данные карточки и её диалог редактирования.

## Требования
- Новый enum `CardLinkTarget` в `Adashboard.Domain/Enums` со значениями `NewTab` и `SameTab` (по аналогии с `UrlScheme` и `CardStatusMode`), XML-комментарий только в виде `<summary>`.
- Свойство `LinkTarget` типа `CardLinkTarget` с значением по умолчанию `NewTab` добавить в контракт `DashboardCard` и в сущность БД `DashboardCardEntity`; XML-комментарий в стиле существующих свойств.
- EF-миграция в `Adashboard.Data/Migrations` добавляет столбец с значением по умолчанию `NewTab` для существующих строк (текущие карточки продолжают открываться в новой вкладке). Миграцию создавать через `dotnet ef` и не применять к базе без запроса.
- Маппинг Mapster не трогать: имена свойств совпадают, соответствие «модель ↔ сущность» работает автоматически.
- `Card.razor`: атрибут `target` вычисляется из модели (`_blank` для `NewTab`, `_self` для `SameTab`); `rel="noopener noreferrer"` оставить как есть. Клик в режиме редактирования по-прежнему не должен уводить со страницы (`preventDefault`), при `SameTab` это особенно важно.
- `CardDialog.razor` и `CardDialog.razor.css`: переключатель-кнопка рядом с полем «Ссылка», в той же строке, что и кнопка схемы (по аналогии с `card-dialog__scheme`): по клику переключает `NewTab` ↔ `SameTab`, показывает иконку Font Awesome текущего режима и подсказку/`aria-label` с названием режима («Новая вкладка» / «Текущая вкладка»). Внешний вид — в существующем стиле диалога (CSS-переменные `--surface`, `--surface-border`, `--accent`).
- Режим открытия сохраняется в `SaveAsync` вместе с остальными полями и восстанавливается в `CardEditModel.FromCard`.
- Подпись «новая вкладка» не должна вводить в заблуждение по доступности: у кнопки есть `title` и `aria-label`, состояние читается скринридером.
- Существующие карточки без явно заданного значения получают `NewTab`; ручной `UPDATE` данных не требуется.

## Критерии приёмки
- [ ] Решение собирается: `dotnet build` проходит без ошибок и новых предупреждений.
- [ ] В диалоге карточки у поля «Ссылка» есть кнопка переключения способа открытия; клик циклично переключает режимы и сразу отражает выбранный вариант.
- [ ] После сохранения карточки и перезагрузки страницы выбранный режим сохраняется (значение приходит из API и показывается в диалоге).
- [ ] Карточка с режимом «Новая вкладка» открывается в новой вкладке, с режимом «Текущая вкладка» — в текущей.
- [ ] В режиме редактирования клик по карточке открывает диалог и не выполняет переход ни в одном из режимов.
- [ ] Существующие карточки после обновления открываются как раньше — в новой вкладке.
- [ ] Миграция создана, но не применена к базе.
